# yimingyang2026.github.io

Homepage of Yiming Yang (Carnegie Mellon University), served by GitHub Pages at https://yimingyang2026.github.io.

Plain static HTML, no build step:

- `index.html`: profile, research, teaching
- `publications.html`: publication list, grouped by year
- `assets/`: stylesheet and photo
- `files/`: CV and course syllabus PDFs

To add a paper, copy an existing `<li>` in `publications.html` under the right year.
To preview locally: `python3 -m http.server` and open http://localhost:8000.
